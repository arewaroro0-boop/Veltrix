* Secure authentication
* Password hashing
* Session management
* HTTPS
* CSRF protection
* XSS protection
* Input validation
* Server-side authorization
* Rate limiting
* Secure cookies
* Access control
* API authentication

# 🌐 Why Use a Local Server?

A local web server is recommended because some browser features and third-party integrations behave differently when pages are opened directly through:

```text
file://
```

Using:

```text
http://localhost
```

provides a more realistic development environment.

It is especially useful for:

* Google Translate
* JavaScript modules
* Fetch requests
* APIs
* Dynamic assets
* Browser storage
* Future backend integration
